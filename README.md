# Frontend Portfolio

Portfólio pessoal desenvolvido com HTML5, CSS3 e JavaScript para apresentar meus projetos e habilidades como desenvolvedor Front-End.

🔗 **Acesse:** [diovannymartins.github.io/frontend-portfolio](https://diovannymartins.github.io/frontend-portfolio/)

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## ⚙️ Funcionalidades

- **Menu mobile responsivo** com animação de ícone (hamburguer → X)
- **Dark/Light mode** com persistência via `localStorage`
- **Scroll reveal** — seções aparecem com fade-in ao rolar a página
- **Link ativo no menu** conforme a seção visível na tela
- **Botão voltar ao topo**
- **Filtro de projetos por categoria**
- **Efeito de digitação (typing effect)** no título principal
- **Formulário de contato com validação** em tempo real
- **Botão de copiar e-mail** com feedback visual
- **Totalmente responsivo** (desktop, tablet e mobile)

## ♿ Acessibilidade

- Labels associados a todos os campos de formulário
- `aria-live` nas mensagens de erro do formulário
- `aria-pressed` nos botões de filtro
- Ícones locais (sem dependência de CDN externo)
- Imagens otimizadas em WebP
