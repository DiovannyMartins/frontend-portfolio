## ✨ Funcionalidades

### 🎨 Interface & UX
- **Design responsivo** — adaptável a desktop, tablet e mobile
- **Dark/Light mode** — alternância de tema com persistência via `localStorage`
- **Animações suaves** — scroll reveal, hover effects e transições
- **Botão voltar ao topo** — aparece ao rolar a página com animação fade

### 🧭 Navegação
- **Menu mobile responsivo** — animação de ícone (hamburguer → X)
- **Scroll spy** — link ativo no menu conforme a seção visível
- **Skip link** — acessibilidade para navegação por teclado

### 📂 Projetos
- **Filtro por categoria** — Dashboard, Landing Page, E-commerce
- **Busca em tempo real** — encontre projetos por título ou descrição
- **Cards interativos** — hover effects e links externos

###  Contato
- **Formulário com validação** — feedback visual em tempo real (bordas verdes/vermelhas)
- **Botão copiar e-mail** — com toast notification de confirmação
- **Links para redes sociais** — GitHub, LinkedIn, Instagram

### ♿ Acessibilidade
- **ARIA labels** em todos os elementos interativos
- **aria-live** nas mensagens de erro do formulário
- **aria-pressed** nos botões de filtro
- **aria-current** no link ativo do menu
- **Focus visible** customizado para navegação por teclado
- **Imagens otimizadas** em WebP com lazy loading

##  Estrutura do Projeto

```
frontend-portfolio/
├── css/
│   ├── base/           # Reset, variáveis e tipografia
│   ├── components/     # Estilos de cada componente (header, hero, cards, etc.)
│   ├── utils/          # Utilitários (acessibilidade, animações)
│   └── main.css        # Ponto de entrada (importa todos os módulos)
├── js/
│   ├── modules/        # Módulos isolados (menu, tema, formulário, etc.)
│   └── main.js         # Ponto de entrada (inicializa todos os módulos)
├── img/                # Imagens e ícones (WebP otimizado)
├── index.html          # Página principal
├── robots.txt          # Diretrizes para mecanismos de busca
├── sitemap.xml         # Mapa do site para SEO
└── README.md           # Documentação do projeto
```

## 🚀 Como Usar

### 1. Clone o repositório
```bash
git clone https://github.com/DiovannyMartins/frontend-portfolio.git
```

### 2. Entre na pasta do projeto
```bash
cd frontend-portfolio
```

### 3. Abra o arquivo `index.html`
Basta abrir no navegador ou usar uma extensão como **Live Server** no VS Code.
